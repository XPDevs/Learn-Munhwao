# Learn-Munhwao Quality Control

## Language verification

Check:

- North Korean spelling.
- Vocabulary meanings.
- Grammar explanations.
- Pronunciation explanations.
- Example translations.
- Formal and informal usage.
- Regional and historical forms.

## Lesson requirements

Every completed lesson should contain:

- A clear objective.
- A teaching explanation.
- Multiple examples.
- Relevant vocabulary.
- Guided practice.
- Independent practice.
- Review questions.
- Answer keys or marking criteria.

## Assessment requirements

Learners should demonstrate that they can:

- Read unfamiliar sentences.
- Understand longer texts.
- Construct grammatically correct sentences.
- Write connected paragraphs.
- Translate accurately.
- Explain grammatical decisions.

## Listening and speaking

Text exercises cannot establish listening comprehension.

Browser speech recognition is not a validated Munhwao
pronunciation examiner.

Do not claim listening proficiency without real listening
tasks using appropriately sourced speech.

## Independent review

Seek qualified Korean linguists and, where possible,
people with native Munhwao experience before claiming
specialist or institutional approval.

## Draft status

The expansion is a curriculum scaffold. It is not
an independently verified advanced course.
